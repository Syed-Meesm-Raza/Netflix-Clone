# Netflix Clone

A fully responsive Netflix landing page clone built with HTML and CSS — no frameworks or libraries used.

---

## Overview

This project is a frontend recreation of the Netflix homepage. It includes a hero section, feature showcases, a pure CSS FAQ accordion, and a fully structured footer — all responsive across desktop and mobile.

---

## Tech Stack

**HTML5:** Structure and layout 

**CSS3:** Styling, animations, responsiveness  

**Font Awesome:** Icons  

**Google Fonts:** Google Sans typography  

> No frameworks, libraries, or JavaScript used.  
> This is a **static frontend clone** — it does **not connect to any backend or stream content**.

---

## Features

### Hero Section
- Full-screen background image with overlay
- Email input form with Get Started button
- Responsive layout for all screen sizes

### Feature Sections
- TV, mobile, and multi-device sections
- Embedded video overlaid on device mockup images

### FAQ Accordion
- Pure CSS accordion — no JavaScript
- Toggle open/close using hidden checkbox trick
- Plus icon rotates to × on open

### Navigation
- Netflix logo and Sign In button
- Language selector dropdown

### Footer
- 4-column link grid (2-column on mobile)
- Language selector
- Fully responsive

---

## How to Run

```
1. Clone or download the repository
2. Open index.html in any modern browser
```

> No installs or build tools needed — it's plain HTML and CSS.
